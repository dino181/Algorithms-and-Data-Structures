# Algorithms-and-Data-Structures
Just a collection of algorithms and data structures to learn and implement them. 

## Language
Language of choice: Rust

Reason: 
- Focus on the algorithms/data structurs
- Familiar language, but also good to reinforce one
- Doesn't make sense to do it in high level languages (e.g. python/c#)
- Don't want to fiddle around with memory management but focus on how the algorithms/data structures work
